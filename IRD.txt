## 1 — SYSTEM ARCHITECTURE OVERVIEW

### 1.1 Architecture Philosophy

WorldGaming is a fully edge-native platform — every component runs on Cloudflare's global network. There are no VMs, no load balancers, and no manually scaled infrastructure. The system is designed on three structural principles derived directly from the PRD:

1. **Edge-first, server-last** — Hot data (sessions, odds, suspension flags, liability) lives in KV and Durable Objects at the Cloudflare edge. PlanetScale is the system of record, not the critical path for live reads.
2. **Fail closed on suspension** — KV suspension flag reads precede all database queries in the bet placement pipeline. A suspended market costs < 1ms to reject; it does not touch PlanetScale.
3. **Atomic money, always** — Every wallet mutation executes inside a PlanetScale database transaction. Partial writes are architecturally impossible.

### 2.2 Request Flow — Bet Placement

```mermaid
sequenceDiagram
    participant Browser
    participant WAF as Cloudflare WAF
    participant API as API Worker (Hono)
    participant KV
    participant DO as BettingSlipDO
    participant PS as PlanetScale
    participant Q as settlement-queue

    Browser->>WAF: POST /api/bets (with sess_token cookie)
    WAF->>API: Pass (IP/geo checks passed)
    API->>KV: GET sess_token → userId, role
    KV-->>API: Session record
    API->>KV: GET suspension flag for matchId
    KV-->>API: Not suspended
    API->>DO: Acquire lock (idempotency key)
    DO-->>API: Lock acquired
    API->>PS: BEGIN TRANSACTION
    API->>PS: SELECT wallet FOR UPDATE
    API->>PS: Validate limits, balance
    API->>PS: UPDATE wallet
    API->>PS: INSERT transaction
    API->>PS: INSERT bet
    API->>PS: COMMIT
    API->>Q: Publish to fraud-analysis-queue (async)
    API->>DO: Release lock
    API-->>Browser: 201 { betId, status: "accepted" }
```

## 3 — CLOUDFLARE DEPLOYMENT ARCHITECTURE

### 3.1 Cloudflare Services Used

| Service | Usage | Configuration |
|---|---|---|
| **Workers** | API, WebSocket routing, feed ingestion, queue consumers | Paid plan; ES module format; Hono framework |
| **Pages** | React SPA hosting (user + admin) | Connected to GitHub repo; auto-deploy on `main` |
| **Durable Objects** | MatchDO, OddsEngineDO, BettingSlipDO, AdminBroadcastDO | Declared in `wrangler.toml`; Hibernation API enabled |
| **KV** | Sessions, odds cache, suspension flags, liability, rate limits | 6 namespaces; eventual consistency acceptable for odds cache, strong reads for sessions |
| **Queues** | Settlement, fraud analysis, audit log | 3 queues; max retries = 3; exponential backoff |
| **R2** | Audit logs (NDJSON), report CSV exports | Two buckets: `worldgaming-audit-logs`, `worldgaming-reports` |
| **D1** | Reference data, audit_log table, odds_history, fraud_flags | SQLite; used for low-write-volume tables |
| **WAF (Custom Rules)** | `/sgyt` IP allowlist, geo-blocking, rate limiting | Configured via Cloudflare dashboard and Terraform |
| **Cloudflare Access** | Zero Trust gate for `/sgyt/*` (Layer 2 admin protection) | TOTP / email OTP |

|---|---|---|---|
| WAF-01 | URI path contains `/sgyt` AND IP NOT IN `admin_ip_allowlist` | Block (HTTP 403) | 1 |
| WAF-02 | URI path contains `/sgyt` AND CF Access token absent | Challenge | 2 |
| WAF-03 | Country NOT IN `allowed_jurisdictions` | Block (HTTP 451) | 3 |
| WAF-04 | Request rate > 1,000/min per IP on `/api/*` | Rate Limit (HTTP 429) | 4 |

## 4 — WORKER AND DURABLE OBJECT RESPONSIBILITIES

### 4.1 Workers

| Worker | Trigger | Responsibilities |
|---|---|---|
| **API Worker** (`worldgaming-api`) | HTTP request to `api.worldgaming.eu.org` | All REST endpoints; auth middleware; session validation; bet placement pipeline; wallet operations; admin CRUD; risk scoring (sync); publishes to all three queues |
| **WebSocket Worker** (`worldgaming-ws`) | HTTP upgrade at `ws.worldgaming.eu.org` | Session validation from KV; routes WS upgrades to correct MatchDO or AdminBroadcastDO |
| **Feed Ingestion Worker** (`worldgaming-feed`) | `cron` trigger (5–30s) + webhook endpoint | Polls EntitySport / API-Sports; receives SportMonks webhook; normalises to internal schema; deduplicates via event fingerprint |
| **Settlement Worker** (`worldgaming-settle`) | `settlement-queue` consumer | Batch processes bet settlement (10 per batch); executes atomic wallet credits; updates bet statuses |
| **Fraud Analysis Worker** (`worldgaming-fraud`) | `fraud-analysis-queue` consumer | Runs async fraud detection rules; writes `fraud_flags` to D1 |
| **Audit Log Worker** (`worldgaming-audit`) | `audit-log-queue` consumer | Writes NDJSON audit entries to R2; append-only |
| **Report Worker** (`worldgaming-report`) | HTTP trigger + daily cron | Queries PlanetScale; generates CSV; stores to R2; returns signed URL |

### 4.2 Durable Objects

#### MatchDurableObject `[P0]`
- **Identity:** `MatchDO.idFromName("match:{matchId}")`
- **State:** `matchState` — score, market states, last update timestamp — persisted to DO storage
- **WebSocket:** Uses Hibernation API (`this.ctx.acceptWebSocket(server)`)
- **On connect:** Sends `{ type: "init", matchState }` snapshot immediately
- **Auto-suspension:** On `wicket | goal | set_complete`, writes `susp:{matchId}=true` to KV; sets alarm for auto-reopen
- **Alarm handler:** Deletes suspension flag from KV; broadcasts `{ type: "market_reopen" }`

#### OddsEngineDurableObject `[P0]`
- **Identity:** `OddsEngineDO.idFromName("odds:engine:{sport}")`
- **Responsibilities:** Applies margin (`final = raw × (1 - margin%)`); validates liability ceiling; writes to KV `ODDS_CACHE`; queues D1 write to `odds_history`; calls MatchDO broadcast
- **Concurrency:** Single-threaded DO prevents margin calculation race conditions

#### BettingSlipDurableObject `[P0]`
- **Identity:** `BettingSlipDO.idFromName("slip:{userId}")`
- **Lock flow:** `acquireLock(idempotencyKey)` → checks existing → stores `{ status:"pending" }` with 60s TTL → on success updates to `{ status:"accepted", betId }` → on failure removes entry
- **Bet delay:** Holds lock during live bet delay (3s default); re-validates odds and suspension before DB write

#### AdminBroadcastDurableObject `[P1]`
- **Identity:** `AdminBroadcastDO.idFromName("admin:broadcast")` — singleton
- **Channels:** `bet_placed`, `risk_alert`, `market_suspension`, `fraud_flag`, `pnl_update`
- **Auth:** Only Workers with `X-Internal-Secret` header can push; admin clients are receive-only

## 5 — BACKEND IMPLEMENTATION STRUCTURE

### 5.1 Framework and Runtime

| Concern | Technology |
|---|---|
| HTTP Framework | Hono v4 |
| Language | TypeScript 5 (strict mode) |
| DB Client (PlanetScale) | `@planetscale/database` HTTP driver |
| DB Client (D1) | CF Workers D1 binding |
| Password Hashing | `@node-rs/argon2` (WASM) — Argon2id, memoryCost=65536, timeCost=3, parallelism=4 |
| Validation | Zod v3 via `@hono/zod-validator` |
| Error Tracking | `@sentry/cloudflare` |

### 5.2 Hono Middleware Stack (execution order)

```
1. Sentry error capture
2. CORS (worldgaming.eu.org origin only, credentials: true)
3. Request ID (UUID v4 injected into every context)
4. Rate limit middleware (KV:RATE_LIMITS)
5. authGuard — reads KV:SESSIONS cacheTtl:0, attaches user to context
6. adminGuard — checks role for /sgyt/* routes + IP hash validation
7. Zod body validation (per-route schema)
8. Route handler
9. Response formatter (standard JSON envelope)
```

## 7 — DATABASE SCHEMA AND RELATIONSHIPS

### 7.1 Database Allocation

| Table Group | Database | Rationale |
|---|---|---|
| `users`, `wallets`, `transactions`, `bets`, `bet_selections`, `deposit_requests`, `withdrawal_requests` | **PlanetScale** | Financial tables; ACID transactions; >100 writes/second |
| `matches`, `markets`, `selections`, `leagues`, `sports` | **D1** | Reference data; low write frequency |
| `audit_log`, `odds_history`, `fraud_flags`, `login_history`, `notifications` | **D1** | Append-only historical records; <100 writes/second |

### 7.2 PlanetScale Schema `[P0]`

```sql
-- FILE: workers/api/src/db/migrations/001_initial_schema.sql
-- CODEX: All financial tables go here. No financial table in D1 ever.
-- CODEX: transactions table is INSERT-ONLY — generate NO UPDATE or DELETE paths for it.

CREATE TABLE users (
  id              VARCHAR(26) PRIMARY KEY,           -- ULID
  username        VARCHAR(50) UNIQUE NOT NULL,
  password_hash   VARCHAR(255) NOT NULL,             -- Argon2id
  status          ENUM('active','suspended','banned') NOT NULL DEFAULT 'active',
  betting_enabled BOOLEAN NOT NULL DEFAULT true,
  role            ENUM('user') NOT NULL DEFAULT 'user',
  agent_id        VARCHAR(26) REFERENCES users(id),
  max_bet         DECIMAL(12,2) NOT NULL,
  max_bet_per_day DECIMAL(12,2) NOT NULL,
  max_win_per_day DECIMAL(12,2) NOT NULL,
  allowed_sports  JSON NOT NULL,
  created_at      TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  created_by      VARCHAR(26) NOT NULL,
  INDEX idx_username (username),
  INDEX idx_status (status),
  INDEX idx_agent_id (agent_id)
);

CREATE TABLE admin_users (
  id              VARCHAR(26) PRIMARY KEY,
  username        VARCHAR(50) UNIQUE NOT NULL,
  password_hash   VARCHAR(255) NOT NULL,
  role            ENUM('superadmin','senior_admin','agent','readonly_admin') NOT NULL,
  status          ENUM('active','suspended') NOT NULL DEFAULT 'active',
  agent_ceiling_max_bet DECIMAL(12,2),
  created_at      TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  created_by      VARCHAR(26),
  INDEX idx_role (role)
);

CREATE TABLE wallets (
  id                  VARCHAR(26) PRIMARY KEY,
  user_id             VARCHAR(26) UNIQUE NOT NULL REFERENCES users(id),
  balance             DECIMAL(14,2) NOT NULL DEFAULT 0.00,
  bonus               DECIMAL(14,2) NOT NULL DEFAULT 0.00,
  pending_withdrawal  DECIMAL(14,2) NOT NULL DEFAULT 0.00,
  frozen              BOOLEAN NOT NULL DEFAULT false,
  currency            CHAR(3) NOT NULL DEFAULT 'INR',
  updated_at          TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_user_id (user_id)
);

-- CODEX: INSERT ONLY. Never generate UPDATE or DELETE statements for this table.
CREATE TABLE transactions (
  id             VARCHAR(26) PRIMARY KEY,
  wallet_id      VARCHAR(26) NOT NULL REFERENCES wallets(id),
  user_id        VARCHAR(26) NOT NULL,
  type           ENUM('deposit','withdrawal','bet_stake','bet_win','bet_refund',
                      'cashout','bonus','admin_credit','admin_debit') NOT NULL,
  amount         DECIMAL(14,2) NOT NULL,
  balance_before DECIMAL(14,2) NOT NULL,
  balance_after  DECIMAL(14,2) NOT NULL,
```

## 8 — KV NAMESPACE DESIGN

| Namespace | Key Pattern | Value | TTL | Notes |
|---|---|---|---|---|
| `SESSIONS` | `sess:{token}` | `{ userId, username, balance, deviceFP }` | 86400s sliding | `cacheTtl:0` always |
| `ADMIN_SESSIONS` | `asess:{token}` | `{ adminId, role, ipHash }` | 28800s non-sliding | IP mismatch → delete + 401 |
| `SESSIONS` | `user_sessions:{userId}` | `["sess:tok1","sess:tok2"]` | 90000s | Bulk revocation index |
| `ODDS_CACHE` | `odds:{matchId}:{marketId}` | `{ selections:[{id,odds}], updatedAt }` | DO-managed | Eventual consistency OK |
| `SUSPENDED_MARKETS` | `susp:{matchId}` | `"1"` | Set by DO alarm | `cacheTtl:0` — NEVER cache |
| `MARKET_LIABILITY` | `lia:{matchId}:{marketId}:{selectionId}` | `{ totalStaked, totalPotentialPayout }` | No TTL | Updated per bet |
| `RATE_LIMITS` | `rl:login:{ip}` | count string | 900s | DO counter for login (not raw KV) |
| `RATE_LIMITS` | `rl:api:{ip}` | count string | 60s | KV acceptable |
| `RATE_LIMITS` | `rl:bet:{userId}` | count string | 60s | 20 bets/min ceiling |
| `FEED_DEDUP` | `dedup:{fingerprint}` | `"1"` | 300s | SHA-256 of matchId+eventType+ts+data |

> **CODEX — KV consistency rules:**
> - `SUSPENDED_MARKETS` reads: always `{ cacheTtl: 0 }` — a cached miss allows a bet on a suspended market (P0 bug)
> - `SESSIONS` reads: always `{ cacheTtl: 0 }` — stale session = auth bypass
> - `ODDS_CACHE` reads: default cache OK — 1–2s stale is acceptable; DB is settlement authority

### 9.2 authGuard Middleware `[P0]`

```typescript
// FILE: workers/api/src/middleware/authGuard.ts
// CODEX: Export as named async function (c: Context, next: Next).
// CODEX: Use getCookie from hono/cookie. cacheTtl:0 is MANDATORY — never omit.
// CODEX: Slide TTL on EVERY authenticated request (PUT with same TTL).
// CODEX: Attach session to context via c.set("user", session).
export async function authGuard(c: Context, next: Next) {
  const token = getCookie(c, "sess_token")
  if (!token) return c.json({ error: "UNAUTHORIZED" }, 401)

  const session = await c.env.SESSIONS.get(`sess:${token}`, {
    type: "json",
    cacheTtl: 0,   // CRITICAL — never remove this option
  })
  if (!session) return c.json({ error: "SESSION_EXPIRED" }, 401)

  // Slide TTL
  await c.env.SESSIONS.put(`sess:${token}`, JSON.stringify(session), {
    expirationTtl: 86400,
  })

  c.set("user", session)
  await next()
}
```

### 9.3 Admin Session Differences

| Property | User Sessions | Admin Sessions |
|---|---|---|
| KV Namespace | `SESSIONS` | `ADMIN_SESSIONS` |
| Prefix | `sess:` | `asess:` |
| TTL | 86400s sliding | 28800s **non-sliding** |
| IP binding | None | `ipHash` stored; mismatch → delete session + 401 |
| Role | Implicit (always 'user') | Stored: `superadmin\|senior_admin\|agent\|readonly_admin` |

### 9.4 adminGuard Middleware `[P0]`

```typescript
// FILE: workers/api/src/middleware/adminGuard.ts
// CODEX: Returns a factory: adminGuard(allowedRoles[]).
// CODEX: IP hash check must execute on EVERY /sgyt/* request, not just login.
// CODEX: Session delete + 401 on IP mismatch — do not just return 403.
export function adminGuard(allowedRoles: AdminRole[]) {
  return async (c: Context, next: Next) => {
    const token = getCookie(c, "sess_token")
    const session = await c.env.ADMIN_SESSIONS.get(`asess:${token}`, {
      type: "json", cacheTtl: 0,
    })
    if (!session) return c.json({ error: "UNAUTHORIZED" }, 401)
    if (!allowedRoles.includes(session.role)) return c.json({ error: "FORBIDDEN" }, 403)

    const currentIpHash = await sha256(c.req.header("CF-Connecting-IP") ?? "")
    if (session.ipHash && session.ipHash !== currentIpHash) {
      await c.env.ADMIN_SESSIONS.delete(`asess:${token}`)
      return c.json({ error: "SESSION_IP_MISMATCH" }, 401)
    }

    c.set("admin", session)
    await next()
  }
}
```

### 9.5 Account Suspension — Instant Revocation `[P0]`

```typescript
// FILE: workers/api/src/services/userService.ts → suspendUser()
// CODEX: Step order is critical. DB update first, then KV purge. All three steps required.
// CODEX: Promise.all for parallel KV deletes — do not await sequentially.
async function suspendUser(userId: string, adminId: string, env: Env) {
  await ps.execute("UPDATE users SET status='suspended' WHERE id=?", [userId])

  const sessionIndex = await env.SESSIONS.get(
    `user_sessions:${userId}`, { type: "json" }
  )
  if (sessionIndex?.length) {
    await Promise.all(sessionIndex.map((key: string) => env.SESSIONS.delete(key)))
    await env.SESSIONS.delete(`user_sessions:${userId}`)
  }

  await auditService.logAction({ action: "user.suspend", adminId, entityId: userId })
}
```

## 10 — WEBSOCKET AND REALTIME IMPLEMENTATION

### 10.1 WebSocket Worker `[P0]`

```typescript
// FILE: workers/websocket/src/worker.ts
// CODEX: Validate sess_token from KV (cacheTtl:0) BEFORE WebSocket upgrade.
// CODEX: /match/:matchId routes to MatchDO; /admin routes to AdminBroadcastDO.
// CODEX: Pass X-User-Id header to DO so it can tag the connection.
export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const token = getCookieFromRequest(request, "sess_token")
    const session = await env.SESSIONS.get(
      `sess:${token}`, { type: "json", cacheTtl: 0 }
    )
    if (!session) return new Response("Unauthorized", { status: 401 })

    const url = new URL(request.url)
    const matchRoute = url.pathname.match(/^\/match\/([a-z0-9]+)$/)
    if (matchRoute) {
      const doId = env.MATCH_DO.idFromName(`match:${matchRoute[1]}`)
      const stub = env.MATCH_DO.get(doId)
      return stub.fetch(new Request(request, {
        headers: { ...Object.fromEntries(request.headers), "X-User-Id": session.userId }
      }))
    }

    if (url.pathname === "/admin") {
      const adminSession = await env.ADMIN_SESSIONS.get(
        `asess:${token}`, { type: "json", cacheTtl: 0 }
      )
      if (!adminSession) return new Response("Forbidden", { status: 403 })
      return env.ADMIN_BROADCAST_DO.get(
        env.ADMIN_BROADCAST_DO.idFromName("admin:broadcast")
      ).fetch(request)
    }

    return new Response("Not Found", { status: 404 })
  }
}
```

### 10.2 MatchDurableObject `[P0]`

```typescript
// FILE: workers/durable-objects/src/MatchDurableObject.ts
// CODEX: Use Hibernation API — ctx.acceptWebSocket(server), ctx.getWebSockets().
// CODEX: blockConcurrencyWhile() in constructor to restore matchState on cold start.
// CODEX: Internal updates authenticated via X-Internal-Secret header check.
// CODEX: triggerAutoSuspension() writes KV and sets DO alarm — both required.
export class MatchDurableObject {
  constructor(private state: DurableObjectState, private env: Env) {
    state.blockConcurrencyWhile(async () => {
      const stored = await state.storage.get<MatchState>("matchState")
      if (stored) this.matchState = stored
    })
  }

  async alarm() {
    // Auto-reopen: delete KV suspension flag, broadcast market_reopen
    const matchId = await this.state.storage.get<string>("matchId")
    await this.env.SUSPENDED_MARKETS.delete(`susp:${matchId}`)
    this.broadcast({ type: "market_reopen", matchId })
  }

  private broadcast(payload: object) {
    const msg = JSON.stringify(payload)
    for (const ws of this.state.getWebSockets()) {
      try { ws.send(msg) } catch { /* hibernation handles dead connections */ }
    }
  }
}
```

### 12.2 walletService — Atomic Pattern `[P0]`

```typescript
// FILE: workers/api/src/services/walletService.ts
// CODEX: This is the ONLY file that writes to wallets and transactions tables.
// CODEX: credit() and debit() must always be called inside an existing PS transaction.
// CODEX: balance_before and balance_after are REQUIRED on every transactions INSERT.
// CODEX: Use Decimal.js for all arithmetic — never native JS floats.
export async function credit(
  tx: PlanetScaleTransaction,
  userId: string,
  amount: Decimal,
  type: TransactionType,
  referenceId?: string,
  note?: string
) {
  const [wallet] = await tx.execute(
    "SELECT id, balance, frozen FROM wallets WHERE user_id = ? FOR UPDATE",
    [userId]
  )
  if (wallet.frozen) throw new WalletFrozenError()
  if (amount.lte(0)) throw new InvalidAmountError()

  const balanceBefore = new Decimal(wallet.balance)
  const balanceAfter = balanceBefore.plus(amount)

  await tx.execute(
    "UPDATE wallets SET balance = ?, updated_at = NOW() WHERE id = ?",
    [balanceAfter.toString(), wallet.id]
  )
  await tx.execute(
    `INSERT INTO transactions
       (id, wallet_id, user_id, type, amount, balance_before, balance_after,
        reference_id, note, created_at)
     VALUES (?,?,?,?,?,?,?,?,?,NOW())`,
    [ulid(), wallet.id, userId, type, amount.toString(),
     balanceBefore.toString(), balanceAfter.toString(), referenceId, note]
  )
}
```

### 12.4 Cashout Service `[P1]`

```typescript
// FILE: workers/api/src/services/cashoutService.ts
// CODEX: Formula: (currentOdds / oddsAtPlacement) * totalStake * (1 - cashoutMargin)
// CODEX: cashoutMargin comes from admin settings KV key — not hardcoded.
// CODEX: Entire operation inside one PS transaction: wallet credit + bet status update.
// CODEX: releaseMarketLiability() must be called inside the same transaction.
async function executeCashout(betId: string, userId: string, env: Env) {
  const bet = await getBet(betId)
  if (bet.status !== "open") throw new Error("BET_NOT_OPEN")

  const currentOdds = await getCurrentOddsForBet(bet, env)
  const cashoutMargin = await getAdminSetting("cashout_margin", env)
  const cashoutValue = (currentOdds / bet.oddsAtPlacement)
    * bet.totalStake * (1 - cashoutMargin)

  if (cashoutValue <= 0) throw new Error("CASHOUT_BLOCKED_NEGATIVE_VALUE")

  await ps.transaction(async (tx) => {
    await walletService.credit(tx, userId, cashoutValue, "cashout", betId)
    await tx.execute(
      "UPDATE bets SET status='settled', outcome='cashout', settled_amount=?, settled_at=NOW() WHERE id=?",
      [cashoutValue, betId]
    )
    await releaseLiability(bet, env)
  })
}
```

### 12.5 Settlement Pipeline `[P0]`

Settlement is triggered by admin submitting match result (`POST /api/sgyt/matches/:matchId/result`):

1. API Worker: updates `match.status='completed'`, suspends all markets in D1 + KV, paginates open bets (100/page), publishes bet IDs in batches of 10 to `settlement-queue`
2. Settlement Worker: evaluates each bet against result; winning bets → `walletService.credit()` (type=`bet_win`); losing → status update only; void → `walletService.credit()` (type=`bet_refund`)
3. Re-settlement: Super Admin triggers → all prior settlements voided (stake refunded) → re-settled with corrected result → full audit trail written

```typescript
// FILE: workers/settlement/src/settlementProcessor.ts
// CODEX: Check bet.status !== 'open' first — makes processing idempotent.
// CODEX: releaseMarketLiability() must be INSIDE the PS transaction, not after.
// CODEX: notifyUserSettlement() is fire-and-forget — do not await it before ack().
async function processSettlement(betId: string, matchResult: MatchResult, env: Env) {
  const bet = await getBetWithSelections(betId)
  if (bet.status !== "open") return  // idempotent

  const outcome = evaluateOutcome(bet.selections, matchResult)

  await ps.transaction(async (tx) => {
    if (outcome === "win") {
      await walletService.credit(tx, bet.userId, bet.potentialPayout, "bet_win", betId)
      await tx.execute(
        "UPDATE bets SET status='settled', outcome='win', settled_amount=?, settled_at=NOW() WHERE id=?",
        [bet.potentialPayout, betId]
      )
    } else if (outcome === "loss") {
      await tx.execute(
        "UPDATE bets SET status='settled', outcome='loss', settled_amount=0, settled_at=NOW() WHERE id=?",
        [betId]
      )
    }
    await releaseMarketLiability(bet, env)
  })

  notifyUserSettlement(bet, outcome, env)  // fire-and-forget
}
```

### 14.3 Kill Switch `[P0]`

```typescript
// FILE: workers/api/src/routers/adminOddsRouter.ts → POST /api/sgyt/markets/suspend-all
// CODEX: Bulk KV writes must complete (Promise.all) before response.
// CODEX: AdminBroadcastDO notify is best-effort — do not fail if DO unreachable.
// CODEX: auditService.logAction() required before return.
async function globalKillSwitch(env: Env, adminId: string) {
  const liveMatches = await env.DB_D1.prepare(
    "SELECT id FROM matches WHERE status='live' AND betting_open=1"
  ).all()

  await Promise.all(
    liveMatches.results.map((m: any) =>
      env.SUSPENDED_MARKETS.put(`susp:${m.id}`, "1")
    )
  )

  try {
    const adminDO = env.ADMIN_BROADCAST_DO.get(
      env.ADMIN_BROADCAST_DO.idFromName("admin:broadcast")
    )
    await adminDO.fetch(new Request("https://internal/broadcast", {
      method: "POST",
      headers: { "X-Internal-Secret": env.INTERNAL_SECRET },
      body: JSON.stringify({
        type: "global_kill_switch",
        matchIds: liveMatches.results.map((m: any) => m.id)
      })
    }))
  } catch { /* best-effort */ }

  await auditService.logAction({
    action: "market.kill_switch_activated", adminId, entityType: "platform", entityId: "*"
  }, env)
}
```

## 15 — RISK AND FRAUD ENGINE IMPLEMENTATION

### 15.1 Risk Scoring `[P1]`

```typescript
// FILE: workers/api/src/services/riskService.ts
// CODEX: Must complete in <20ms. Zero PlanetScale reads inside this function.
// CODEX: All inputs pre-fetched from KV or passed in the bet request.
// CODEX: risk_score clamped 0.0–1.0. Threshold: 0.7=flag, 0.9=hold.
interface RiskFactors {
  stakeVsUserAverage:  number   // this stake / user 30-day avg
  stakeVsMarketLimit:  number   // this stake / market.max_liability
  oddsValue:           number   // (odds - 1.0) / 100 normalised
  userRecentPnL:       number   // recent net P&L / max_win_per_day
  userWinRate:         number   // win_count / settled_count
  timeToEvent:         number   // 0=pre-match, 1=live last 5min
  marketLiquidity:     number   // 1.0 / total bets on market
}

const WEIGHTS = {
  stakeVsUserAverage: 0.25, stakeVsMarketLimit: 0.20,
  oddsValue: 0.10, userRecentPnL: 0.20, userWinRate: 0.15,
  timeToEvent: 0.05, marketLiquidity: 0.05,
}

export function calculateRiskScore(factors: RiskFactors): number {
  return Object.entries(WEIGHTS).reduce((score, [factor, weight]) =>
    score + Math.min(factors[factor as keyof RiskFactors], 1.0) * weight
  , 0)
}
```

Thresholds: `0.0–0.69` accept, `0.7–0.89` accept + `review_flag=true`, `0.9–1.0` `status=pending_manual`.

### 15.2 Fraud Rules `[P1]`

### 19.2 Settlement Queue Consumer `[P0]`

```typescript
// FILE: workers/settlement/src/worker.ts
// CODEX: Export queue handler as { async queue(batch, env) }.
// CODEX: message.ack() only after successful PS COMMIT.
// CODEX: message.retry() for RetryableError; message.ack() for non-retryable to prevent DLQ loop.
// CODEX: Alert if queue depth > 1000 after processing batch.
export default {
  async queue(batch: MessageBatch<SettlementMessage>, env: Env): Promise<void> {
    for (const message of batch.messages) {
      try {
        await processSettlement(message.body.betId, message.body.matchResult, env)
        message.ack()
      } catch (error) {
        if (error instanceof RetryableError) {
          message.retry({ delaySeconds: calculateBackoff(message.attempts) })
        } else {
          await logSettlementError(message.body.betId, error, env)
          message.ack()  // non-retryable — ack to prevent infinite retry
        }
      }
    }
  }
}
```

### 19.3 Audit Log Consumer `[P1]`

```typescript
// FILE: workers/audit/src/worker.ts
// CODEX: R2 key pattern: audit-logs/YYYY/MM/DD/HH.ndjson
// CODEX: batch.ackAll() after successful R2 append.
// CODEX: D1 is source of truth if R2 fails — do not fail batch on R2 error alone.
export default {
```

## 26 — SCALABILITY CONSIDERATIONS

- **WebSocket sharding (>100k connections):** `match:{matchId}:shard{n}` — Feed Worker broadcasts to all shards. Phase 1 uses single-shard per match.
- **PlanetScale throughput:** `transactions` is INSERT-only (maximises write throughput); `wallets` uses row-level `FOR UPDATE`; HTTP driver handles connection pooling.
- **D1 ceiling (~100 writes/s):** All audit/odds-history writes are async via queue. No financial data in D1.
- **KV at peak (1,000 bets/min):** `MARKET_LIABILITY` ~1,000 writes/min; `SESSIONS` ~10,000 writes/min — within KV limits.

## 27 — FAILURE RECOVERY

| Failure | Detection | Recovery |
|---|---|---|
| PlanetScale down during bet | DB connection throws | Return 500; BettingSlipDO lock released; idempotency key allows retry |
| PlanetScale down during settlement | Worker catches | Queue retry 3× (30s/60s/120s); DLQ after 3 failures; Telegram alert |
| KV unavailable | KV read throws | Fail closed — reject the bet. Never assume market is open on KV error |
| MatchDO cold start | Constructor fires | `blockConcurrencyWhile` restores matchState from DO storage |
| Feed Worker / external API down | No response > 60s | Sentry alert; auto-suspend all live markets for affected sport |
| SportMonks webhook failure | Expected webhook not received | Polling fallback at 30s interval |
| Settlement DLQ overflow | DLQ depth > 100 | PagerDuty critical; manual DLQ processing by Super Admin |
| R2 audit write failure | Audit Worker exception | Retry 5×; D1 remains source of truth |
| Worker deploy failure | Wrangler non-zero exit | GitHub Actions fails; Wrangler preserves last-deployed version automatically |

## 28 — EDGE CASE HANDLING

| Scenario | Handling |
|---|---|
| Odds change > 5% during live bet delay | Return `ODDS_CHANGED`; user must re-confirm before DB write |
| User places bet then immediately suspends market | KV suspension check is first step; bet rejected even if DB write started |
| Accumulator with one voided leg | Entire accumulator voided; full stake refunded |
| Re-settlement after admin error | All affected bets voided (stake refunded), then re-evaluated against corrected result; full audit trail |
| Withdrawal requested on same funds as open bet | `available_balance = balance - pending_withdrawal - SUM(open_bets.stake)` prevents double-spend |
| Admin creates user with same username (race) | UNIQUE constraint on `users.username`; returns 409 `DUPLICATE_USERNAME` |
| Feed delivers duplicate event | SHA-256 fingerprint + 300s KV dedup prevents duplicate DO updates |
| MatchDO alarm fires but match already reopened | `SUSPENDED_MARKETS.delete` is idempotent; no-op if key absent |
| BettingSlipDO lock expires mid-delay | 60s TTL exceeds 3s delay; lock always valid during delay window |
| Admin IP changes mid-session | `SESSION_IP_MISMATCH` → session deleted → redirect to admin login |
